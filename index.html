隐私政策

版本更新时间：2026-06-08

欢迎使用 时间清单。本隐私政策说明我们如何处理您在使用本应用过程中产生的数据与隐私信息。请在使用前仔细阅读。

1. 我们收集的信息

  • 应用内生成的本地业务内容：待办事项、日志、灵感内容、标签与状态信息。
  • 应用设置与偏好：如界面显示设置、备份入口引导状态等。
  • 备份与恢复文件：用于 JSON 导出与恢复的数据文件，默认保存在本地，用户可选择性导入/导出。
  • 如联系反馈功能被使用：我们会获取您填写的邮箱和反馈内容用于回复处理。

2. 信息处理方式

  • 除非您主动上传反馈内容，本应用默认将核心数据保存在您的设备本地。
  • 备份文件默认导出到本地目录，由您自主保存和管理，不会自动上传至服务器。
  • 如您使用系统文件导入功能，文件访问范围仅限于您明确选择的文件。

3. 数据共享与第三方服务

  • 我们不会将您的任务内容、日志、灵感或导出的备份文件出售、共享或广告化。
  • 除法律法规要求或用户同意外，不会将上述信息向第三方披露。
  • 如您与客服联系时，您提供的邮箱和问题描述仅用于处理问题与服务支持。

4. 您的权利

  • 可随时删除应用内数据或重置内容。
  • 可随时导出或导入 JSON 备份并用于自主管理。
  • 可选择卸载应用以移除设备上的本地数据。

5. 安全与风险提示

  • 恢复备份操作将覆盖当前本地数据，请在恢复前确认备份文件来源可信。
  • 请妥善保管备份文件和邮箱凭据，避免向不可信来源传输敏感内容。
