隐私政策

版本更新时间：2026-06-10

欢迎使用 时间清单。本隐私政策说明我们如何处理您在使用本应用过程中产生的数据与隐私信息。请在使用前仔细阅读。

1. 应用处理的信息

以下内容主要保存在您的设备本地。除非您主动通过邮件、系统分享或文件导出等方式发送给我们，否则我们不会主动收集或上传这些内容。

  • 应用内生成的本地业务内容：待办事项、日志、灵感内容、标签与状态信息。
  • 应用设置与偏好：如界面显示设置、备份入口引导状态等。
  • 备份与恢复文件：用于 JSON 导出与恢复的数据文件，默认保存在本地，用户可选择性导入/导出。
  • 如您主动通过邮件联系我们：我们会收到您的邮箱地址、邮件内容及您主动提供的附件，仅用于回复问题和提供支持。

2. 信息处理方式

  • 除非您主动上传反馈内容，本应用默认将核心数据保存在您的设备本地。
  • 备份文件默认导出到本地目录，由您自主保存和管理，不会自动上传至服务器。
  • 如您使用系统文件导入功能，文件访问范围仅限于您明确选择的文件。
  • 本应用目前不接入第三方广告 SDK、第三方统计分析 SDK，也不会跨 App 或网站追踪用户。

3. 数据共享与第三方服务

  • 我们不会将您的任务内容、日志、灵感或导出的备份文件出售、共享或广告化。
  • 除法律法规要求或用户同意外，不会将上述信息向第三方披露。
  • 如您通过邮件联系我们，邮件地址、邮件内容及附件会由邮箱服务商处理，并仅用于问题回复与服务支持。

4. 您的权利

  • 可随时在应用内删除单条记录或重置内容。
  • 可随时导出或导入 JSON 备份并用于自主管理。
  • 可选择卸载应用以移除设备上的本地数据。

5. 安全与风险提示

  • 恢复备份操作将覆盖当前本地数据，请在恢复前确认备份文件来源可信。
  • 用户可在任务、日志、灵感中输入自由文本内容，请避免主动记录身份证号、银行卡号、健康信息等敏感信息。
  • 请妥善保管备份文件，避免向不可信来源传输敏感内容。
